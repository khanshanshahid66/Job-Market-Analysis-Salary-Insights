**📊 Job Market Analysis & Salary Insights**

**📌 Project Overview**
An interactive Salary Dashboard designed to help users explore salary trends across data-related roles based on job title, country, and employment type.
The dashboard transforms raw job-market data into an interactive tool for comparing salary levels and understanding how role, location, and job type influence compensation.
 **🎯 Key Features**
•	💰 Median salary analysis by job title
•	🌍 Geographic salary comparison using an Excel Map Chart
•	🔎 Dynamic filtering by job title, country, and employment type
•	📊 Interactive salary dashboard
•	🧮 Multi-criteria salary calculations using Excel formulas
•	✅ Data validation for controlled user inputs
•	📈 Visual comparison of salaries across data-related roles

**🛠️ Excel Skills Used**
•	Charts & Data Visualization
•	Formulas & Functions
•	MEDIAN & IF
•	FILTER
•	SEARCH
•	Data Validation
•	Dynamic Filtering
•	Map Charts

**📂Dataset**
The dataset contains real-world data science job information from 2023, including:
•	Job titles
•	Salaries
•	Countries
•	Employment types
•	Required skills

**💰 Salary Analysis**
A multi-criteria Excel formula calculates the median salary based on:
•	Job Title
•	Country
•	Employment Type
•	Available salary data
This allows users to generate salary estimates based on their selected criteria.

**🌍 Geographic Analysis**
An Excel Map Chart visualizes median salaries across countries, making it easier to identify geographic salary differences.

**🔎 Interactive Filters**
Data Validation dropdowns allow users to select:
Job Title → Country → Employment Type
The dashboard dynamically updates based on these selections.

**📊 Dashboard Insights**
The dashboard provides a quick way to identify:
•	Differences in salary across data-related roles
•	Higher- and lower-paying job categories
•	Geographic salary variations
•	How employment type can affect salary comparisons
